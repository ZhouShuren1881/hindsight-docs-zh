# Python 客户端 {#python-client}

这是 Hindsight API 的官方 HTTP 客户端。如果你已经运行了 Hindsight 服务器，无论是在本地、Docker 中还是通过托管服务运行，都可以使用这个带类型支持的 Python 客户端与服务器通信。

如果你希望**在 Python 进程中嵌入并运行 Hindsight 服务器**（无需外部服务器），请参阅[嵌入式 Python（hindsight-all）](./hindsight-all.md)。

## 安装 {#installation}

```bash
pip install hindsight-client
```
