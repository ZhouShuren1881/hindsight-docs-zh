Hindsight CLI 提供命令行接口，用于操作记忆和管理记忆库。所有命令均遵循 [OpenAPI 规范](/api-reference)，因此可以在任意命令后使用 `--help` 查看全部可用选项。

## 安装 {#installation}

```bash
curl -fsSL https://hindsight.vectorize.io/get-cli | bash
```

## 配置 {#configuration}

配置 API URL：

<CodeSnippet code={cliSh} section="cli-configure" language="bash" />

也可以不带任何选项运行 `hindsight configure`，按交互式提示进行配置，或使用优先级最高的环境变量：

```bash
export HINDSIGHT_API_URL=http://localhost:8888
export HINDSIGHT_API_KEY=your-api-key
```

### 命名配置文件 {#named-profiles}

如果需要在多个 Hindsight 部署（例如本地、预发布、生产环境）之间切换，又不想反复改写 `~/.hindsight/config`，可以使用命名配置文件。每个配置文件都是位于 `~/.hindsight/cli-profiles/<name>.toml` 的 TOML 文件，可在每次调用时通过 `-p/--profile` 选择，也可以通过设置 `$HINDSIGHT_PROFILE` 来选择。

<CodeSnippet code={cliSh} section="cli-profiles" language="bash" />

在 Unix 上，配置文件以 `0600` 权限写入，确保只有所有者能够读取其中的 API 密钥。

**配置优先级**（从高到低）：

1. 环境变量（`HINDSIGHT_API_URL`、`HINDSIGHT_API_KEY`）
2. 命名配置文件：优先使用显式指定的 `-p <name>`，否则使用 `$HINDSIGHT_PROFILE`
3. 共享配置文件（`~/.hindsight/config`，由 `hindsight configure` 写入）
4. 默认值（`http://localhost:8888`）

`HINDSIGHT_API_URL` / `HINDSIGHT_API_KEY` 始终覆盖命名配置文件中的值，因此可以在脚本中安全地使用 `-p`，同时允许 CI 通过环境变量注入凭据。

## 控制台界面 {#control-plane-ui}

直接从 CLI 启动基于 Web 的控制台界面：

```bash
hindsight ui
```

此命令使用配置中的 API URL，在本地端口 9999 上运行控制台。该界面提供以下功能：

- **记忆库管理**：浏览和管理所有记忆库
- **实体浏览器**：以可视化方式呈现知识图谱
- **查询测试**：交互式测试 Recall 和 Reflect
- **操作历史记录**：查看摄取和处理日志

:::tip
界面启动命令要求已安装 Node.js。它会通过 npx 自动下载并运行 `@vectorize-io/hindsight-control-plane` 包。
:::

## 交互式浏览器 {#interactive-explorer}

启动终端用户界面（TUI）浏览器，以可视化方式浏览记忆库：

```bash
hindsight explore
```

浏览器提供交互式终端界面，支持以下操作：

- **浏览记忆库**：查看所有记忆库及其统计数据
- **搜索记忆**：执行 Recall 查询并实时查看结果
- **查看记忆详情**：打开记忆，查看文本、元数据、实体和完整的 JSON 字段
- **查看实体**：探索知识图谱和实体关系
- **查看事实**：浏览世界事实、经历事实和观测
- **浏览文档**：查看来源文档及从中提取的记忆
