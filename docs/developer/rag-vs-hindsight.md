# RAG 与记忆 {#rag-vs-memory}

传统 RAG（检索增强生成）会检索与查询相似的文档。Hindsight 则提供结构化记忆，具备时间推理、实体理解和认知判断形成能力。

## 能力对比 {#capability-comparison}

| 能力 | RAG | Hindsight |
|------------|-----|-----------|
| **搜索策略** | 仅语义相似度 | 语义 + 关键词 + 图关系 + 时间 |
| **多跳推理** | 局限于检索到的文本分块 | 沿实体关系遍历图结构 |
| **时间查询** | 关键词匹配（“春天”） | 解析日期并按范围筛选 |
| **实体理解** | 无 | 实体消解、共现跟踪 |
| **知识整合** | 无状态 | 综合生成并不断演变的心智模型 |
| **性格倾向** | 无 | 3 种特质（怀疑、照字面理解、共情）会影响解读 |

## 架构对比 {#architecture-comparison}

### RAG {#rag}

| 步骤 | 操作 |
|------|-----------|
| 1 | 将查询转换为嵌入向量 |
| 2 | 执行向量相似度搜索 |
| 3 | 返回排名靠前的 k 个文本分块 |
| 4 | 生成回答 |

只有一种检索策略。不同查询之间不保留状态。

### Hindsight {#hindsight}

| 步骤 | 操作 |
|------|-----------|
| 1 | 解析查询（提取时间表达和实体） |
| 2 | 并行执行 4 种检索：语义、BM25、图检索、时间检索 |
| 3 | 使用 RRF 融合结果 |
| 4 | 使用交叉编码器重新排序 |
| 5 | 应用性格倾向 |
| 6 | 生成回答 |

采用多种检索策略。跨会话保留持久状态。

## 示例场景 {#example-scenarios}

### 多跳推理 {#multi-hop-reasoning}

**已存入的事实：**
- “Alice 是 Project Atlas 的技术负责人”
- “Project Atlas 使用 Kubernetes”
- “Kubernetes 集群在周二发生过中断”

**查询：**“最近的问题影响到 Alice 了吗？”

| 系统 | 结果 |
|--------|--------|
| RAG | 只检索关于 Alice 的事实（与“问题”没有语义相似性） |
| Hindsight | 通过实体链接遍历 Alice → Project Atlas → Kubernetes → 中断 |

### 时间查询 {#temporal-queries}

**带时间戳的已存入事实：**
- 3 月：“Alice 开始进行微服务迁移”
- 4 月：“Alice 完成了身份验证服务”
- 10 月：“Alice 正在专注于性能”

**查询：**“Alice 去年春天做了什么？”

| 系统 | 结果 |
|--------|--------|
| RAG | 不论日期如何，都会返回所有关于 Alice 的事实 |
| Hindsight | 将“去年春天”解析为 3 月至 5 月，并筛选该时间范围内的事实 |

### 实体理解 {#entity-understanding}

**跨会话记录的用户事实：**
- “Pro 订阅”
- “移动应用在设置页面会崩溃”
- “已改用年度计费”
- “桌面应用运行正常”

**查询：**“你对我的账户了解什么？”

| 系统 | 结果 |
|--------|--------|
| RAG | 列出彼此无关的事实 |
| Hindsight | 通过实体图返回相互关联的事实：订阅状态、计费方式和已知问题 |

### 知识演变 {#knowledge-evolution}

**第 1 周**：用户在使用异步 Python 时遇到困难，但使用线程时进展顺利
**第 3 周**：用户询问 asyncio，并实现了异步数据库调用

| 系统 | 行为 |
|--------|----------|
| RAG | 不会记住这一进展 |
| Hindsight | 整合心智模型“用户更喜欢同步方式”→ 将其修正为“用户正逐渐适应异步方式” |

## 何时使用哪种方案 {#when-to-use-each}

| 使用场景 | 建议方案 |
|----------|-------------|
| 针对静态语料库进行文档问答 | RAG |
| 无时间要求的搜索 | RAG |
| 需要持久记忆的 AI 助手 | Hindsight |
| 需要跟踪实体的应用 | Hindsight |
| 需要一致性格倾向的系统 | Hindsight |
| 时间查询（“上个月”“2023 年”） | Hindsight |
