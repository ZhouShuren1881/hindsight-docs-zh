# 知识页 {#knowledge-pages}

**知识页**是记忆库为自身撰写、持续更新的文档。每个页面回答一个问题，例如“这里有哪些组件？”或“我们的错误处理惯例是什么？”，并随着记忆库了解得更多而改写。知识页按文件夹组织，可供浏览和搜索，也可以投影到磁盘，成为普通的 Markdown 文件。

它的形态像 wiki，底层引擎则是记忆。

## 简化心智模型的使用方式 {#mental-models-simplified}

知识页本身就是一个[心智模型](./mental-models)，综合生成方式、后台刷新机制和来源追溯信息都相同。

不同之处在于，使用知识页需要了解多少内部机制。心智模型会暴露这些机制：它读取什么、何时重建、如何自行编辑。维护 wiki 不应该要求任何人操心综合范围和刷新触发条件。因此，知识页已经替你预先确定了这些设置：

- 它根据记忆库的[观测](./observations)构建——这些观测是经过整合、去重的认知判断，而不是未经处理的对话细节。
- 每当整合在其范围内产生新知识时，它就会增量刷新，编辑文档而不是重新生成整篇文档。
- 它绝不读取其他页面，因此页面之间不会互相引用，形成反馈循环。
- 它获得更大的内容预算，因为它是文档，而不是答案。

你只需提供名称和问题。其他设置都有默认值，需要时可以覆盖；每项心智模型设置仍然适用。具体默认值及其修改方式，请参阅[知识页 API](./api/knowledge-pages)。

## 按 wiki 的方式组织 {#organized-like-a-wiki}

页面存放在文件夹树中。嵌套层级不受限制；页面名称只需在所在文件夹内唯一；删除文件夹也会删除它的整个子树。这就是全部的结构模型——一个层级结构，就像任何人手动整理文档时会采用的方式。

文件夹树让知识库可以导航，而不是一组扁平的综合内容：`Architecture/`、`Runbooks/`、`Decisions/`，每个文件夹中都有会自行保持最新的页面。

## 投影为实际文件 {#projected-as-real-files}

智能体已经知道如何使用文件系统，因此 CLI 可以把记忆库的知识库镜像到磁盘：

```bash
hindsight fs mount --bank my-bank
```

文件夹树会变成实际目录，每个页面会成为带有 YAML frontmatter 的实际 Markdown 文件，并由后台刷新循环持续更新。接下来，常见工具都能直接使用——`ls`、`cat`、`grep`、`rg`、`fzf`、你的编辑器，以及智能体的文件工具。无需 SDK、API 客户端，也不用学习新术语。

相同内容也可以通过 API 获取为可移植的 Markdown 包，以便导出或提交到其他位置。

## 可搜索 {#searchable}

知识页支持**文档级**搜索：查询会返回整篇页面，并按排名附上片段。它结合全文匹配和语义匹配，由服务端融合结果，不经过重排步骤——速度足够快，能成为智能体首先调用的工具。

最后这一点很重要。搜索是智能体*主动选择*调用的工具，调用记录会显示在对话记录中；内容不会在每一轮都自动塞进智能体的上下文。智能体主动请求的检索结果有助于它完成当前工作；未请求的检索结果则往往会让它偏离方向。

这与[召回](./retrieval)是不同的路径；召回搜索的是单条记忆。用页面搜索来选取文档，用召回来查找具体事实。

## 为什么不直接使用原始文件？ {#why-not-just-raw-files}

如果最终答案是文件夹树中的文档，我们是不是重新发明了文件——而文件正是记忆系统要取代的东西？

区别在于底层机制。文件会让信息逐渐过时。最后编辑的人决定最终内容，矛盾会悄悄累积，却始终无人协调处理。若无人维护，手工维护的 wiki 最终会成为一份格式精美的谎言——并非有人故意撒谎，而是让内容始终准确是一件琐事，而琐事往往会被搁置。

知识页是处理后记忆上的**投影视图**，就像数据库视图并不是一张表。在写入页面之前，Hindsight 已经完成文件自身无法完成的工作：从原始会话、提交记录和文档中提取事实；将其去重；并通过整合协调其中的矛盾。因此，当团队先决定 X、之后又将其修订为 Y 时，页面会说明 Y，也可以解释原因，而不是把两段相隔一段文字的内容都保留下来。

原始文档仍然是关于*曾经说过什么*的事实来源。页面呈现的则是经过协调处理的、关于*哪些内容仍然成立*的认知。

这也解释了页面为何会自我修复，而不是逐渐腐坏：页面不是存储本身，而是渲染结果。删除页面不会丢失任何内容——它可以从记忆中重新投影出来。试试看，删除一个 wiki 后能不能把它恢复。

## 使用知识页 {#working-with-pages}

- **控制平面** — 知识库视图会呈现文件夹树、页面内容，以及哪些页面的内容已待更新。
- **HTTP API** — 完整端点列表请参阅[知识页 API](./api/knowledge-pages)。
- **CLI** — `hindsight fs` 会将记忆库镜像到本地文件夹中的 Markdown 文件。
- **智能体工具** — Claude Code 插件会提供 `agent_knowledge_*` MCP 工具，让智能体在会话期间列出、读取、创建和更新自己的页面。
