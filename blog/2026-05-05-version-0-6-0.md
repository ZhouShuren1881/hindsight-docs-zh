Hindsight 0.6.0 是一个重要版本，新增了 **Oracle 23ai 数据库后端**，并集成了 **Dify**、**n8n**、**SmolAgents** 和 **AWS Bedrock AgentCore**，同时显著提升了可靠性。在可靠性方面，存入流程的事务原子性问题得到修复，BM25 搜索排序得到纠正，实体时间线的准确性也有所提高。

<!-- truncate -->

- [**Oracle 23ai 数据库后端**](#oracle-23ai-database-backend)：在 Oracle Database 上运行 Hindsight，满足企业部署需求。
- [**新增集成**](#new-integrations)：Dify、n8n、SmolAgents、AWS Bedrock AgentCore。
- [**存入可靠性**](#retain-reliability)：事务原子性、检查点范围和死锁修复。
- [**搜索与检索修复**](#search--retrieval-fixes)：BM25 分数方向、观测实体继承和时间线准确性。

## Oracle 23ai 数据库后端 {#oracle-23ai-database-backend}

现在，Hindsight 除了 PostgreSQL，还可以使用 **Oracle Database 23ai** 运行。迁移系统已统一到 Alembic，并使用方言分派器：每个迁移文件都包含 PostgreSQL 和 Oracle 的实现，因此两个后端的数据库模式更改可以保持同步。

Oracle 23ai 原生支持向量检索和 JSON 文档存储，因此对于已经运行 Oracle 基础设施的企业而言，是自然的选择。只需将数据库 URL 设置为 Oracle 连接字符串，Hindsight 就会处理其余工作，无需单独设置数据库模式。

## 新增集成 {#new-integrations}

0.6.0 新增了四种框架集成：

- **Dify**（`hindsight-dify`）：在 Dify 工作流中使用 Hindsight 记忆工具，无需离开 Dify 画布即可 Retain（存入）对话上下文、Recall（召回）相关记忆，并通过 Reflect（反思）基于累积的知识进行推理。
- **n8n**（`n8n-nodes-hindsight`）：社区节点包，可将 Hindsight 的存入、召回和反思功能接入 n8n 自动化流程。
- **SmolAgents**（`hindsight-smolagents`）：为 HuggingFace 的 SmolAgents 框架提供记忆工具。
- **AWS Bedrock AgentCore**（`hindsight-agentcore`）：为运行在 Amazon Bedrock AgentCore Runtime 上的智能体提供持久记忆。

## 存入可靠性 {#retain-reliability}

多项修复提升了并发和批处理工作负载下存入操作的正确性：

- **事务原子性**：批量存入现在会以原子方式提交父操作记录和子操作记录，避免失败时留下孤立状态。
- **恢复检查点范围**：异步恢复检查点现在按文档分别限定范围，因此某个文档发生故障不会使其他文档的处理进度失效。
- **级联死锁修复**：现在延迟检查记忆连接到记忆单元的外键约束，从而打破高并发存入时可能出现的死锁模式。

## 搜索与检索修复 {#search--retrieval-fixes}

- **修正 BM25 分数方向**：针对 vchord 后端修正了分数方向。此前，反向的分数可能导致与关键词相关的结果排在最后。
- **观测实体继承**：Recall 现在会通过 `source_memory_ids` 正确继承观测中的实体，因此实体图遍历能够保持相关记忆之间的连续性。
- **实体共现时间戳**：共现记录现在使用事件发生日期（而非摄取时间）标记，从而改善时间查询和时间线准确性。

## 其他显著变化 {#other-notable-changes}

- **OpenCode 工作树共享**：同一代码库的 Git 工作树现在共享记忆库。
- **TypeScript 客户端支持 AbortSignal**：所有 `HindsightClient` 方法都接受 `AbortSignal`，用于取消请求。
- **Python 客户端的 `retain_async`**：`retain()` 和 `aretain()` 方法现在可直接提供异步存入流程。
- **Anthropic 服务提供方配置项**：Anthropic LLM 服务提供方现在支持通过环境变量配置 `max_retries` 和 `default_headers`。
- **时间序列时间字段切换**：统计图表现在可以按不同的时间字段分组。
- **数据库 URL 脱敏**：配置日志不再泄露数据库凭据。
- **增强 OpenAI 兼容服务提供方的健壮性**：改进了 Ollama、LM Studio 和其他 OpenAI 兼容后端的 JSON 响应解析和空内容处理。
- **MCP `tag_groups`**：Recall MCP 工具现在提供 `tag_groups`，支持按条件筛选或分组召回。
- **守护进程主机覆盖**：守护进程模式现在会遵循 `--host` 和 `HINDSIGHT_API_HOST` 的设置。
