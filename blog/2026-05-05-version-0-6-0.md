Hindsight 0.6.0 是一个主要版本，添加了 **Oracle 23ai 数据库后端**、**Dify**、**n8n**、**SmolAgents** 和 **AWS Bedrock AgentCore** 的新集成，以及显著的可靠性改进。在可靠性方面，记忆存储修复了事务原子性，修正了BM25搜索排名，并提高了实体时间线准确性。

<!-- truncate -->

- [**Oracle 23ai 数据库后端**](#oracle-23ai-database-backend)：在 Oracle 数据库上运行 Hindsight 以进行企业部署。
- [**新集成**](#new-integrations)：Dify、n8n、SmolAgents、AWS Bedrock AgentCore。
- [**记忆存储可靠性**](#retain-reliability)：事务原子性、检查点范围、死锁修复。
- [**搜索和检索修复**](#search--retrieval-fixes)：BM25得分方向，观察实体继承，时间线准确性。

## Oracle 23ai 数据库后端 {#oracle-23ai-database-backend}

Hindsight 现在可以在 **Oracle 数据库 23ai** 上运行，作为 PostgreSQL 的替代方案。整个迁移系统已在 Alembic 下通过方言调度程序进行统一——每个迁移文件都包含 PG 和 Oracle 实现，因此架构更改在后端之间保持同步。

Oracle 23ai 原生支持矢量搜索和 JSON 文档存储，非常适合已经运行 Oracle 基础设施的企业。将数据库 URL 设置为 Oracle 连接字符串，Hindsight 处理其余部分 — 无需单独的模式设置。

## 新集成 {#new-integrations}

0.6.0 中提供了四个新的框架集成：

- **Dify** (`hindsight-dify`)：在 Dify 工作流程中使用 Hindsight 记忆工具 — 记忆存储对话上下文、记忆相关记忆以及反思积累的知识，而无需离开 Dify 画布。
- **n8n** (`n8n-nodes-hindsight`)：一个社区节点包，将 Hindsight 存储记忆/记忆召回/梦想带入 n8n 自动化。
- **SmolAgents** (`hindsight-smolagents`)：HuggingFace 的 SmolAgents 框架的记忆工具。
- **AWS Bedrock AgentCore** (`hindsight-agentcore`)：在 Amazon Bedrock AgentCore 运行时上运行的智能体的持久记忆。

## 记忆存储可靠性 {#retain-reliability}

多项修复提高了并发和批量工作负载下记忆存储的正确性：

- **事务原子性**：批量记忆存储现在以原子方式提交父子操作行，防止失败时出现孤立状态。
- **恢复检查点范围**：异步恢复检查点现在的范围仅限于每个文档，因此一个文档中的故障不会使其他文档的进度无效。
- **级联死锁修复**：记忆链接→记忆单元外键现在被推迟，打破了高并发记忆存储下可能出现的死锁模式。

## 搜索和检索修复 {#search--retrieval-fixes}

- **BM25 分数方向已修正** 用于 vchord 后端 — 之前倒置的分数可能会导致与关键字相关的结果排名最后。
- **观察实体继承**：记忆召回现在可以通过`source_memory_ids`正确继承观察实体，因此实体图遍历不会失去相关记忆之间的连续性。
- **实体共现时间戳**：同时出现的事件现在标记有事件日期（而不是摄取时间），从而提高了时间查询和时间线准确性。

## 其他显著变化 {#other-notable-changes}

- **OpenCode 工作树共享**：记忆库现在在同一存储库的 git 工作树之间共享。
- **TypeScript 客户端中止信号**：所有 `HindsightClient` 方法都接受 `AbortSignal` 来取消请求。
- **Python客户端`retain_async`**：`retain()`和`aretain()`方法现在直接公开异步存储记忆流。
- **Anthropic 提供商旋钮**：环境可配置`max_retries`和`default_headers`，用于AnthropicLLM提供商。
- **时间序列时间字段切换**：统计图表现在可以按不同的时间字段进行分组。
- **数据库 URL 编辑**：配置日志记录不再泄漏数据库凭据。
- **OpenAI兼容的提供商强化**：跨Ollama、LM Studio 和其他OpenAI 兼容后端更好的JSON 响应解析和空内容处理。
- **MCP tag_groups**：记忆召回MCP工具现在公开`tag_groups`以进行过滤/分组记忆召回。
- **守护进程主机覆盖**：`--host` 和 `HINDSIGHT_API_HOST` 现在在守护进程模式下受到尊重。
