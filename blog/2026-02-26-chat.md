## 问题：你的团队机器人忘记了一切 {#the-problem-your-team-bot-forgets-everything}

您的团队在 Slack 和 Discord 上使用机器人。有人报告了 Slack 中的一个错误：“移动设备上的结账流程被破坏了。”其他人在 Discord 中提到了一个功能请求：“我们需要深色模式支持。”一周后，总理问机器人：“有哪些未解决的问题？”没有什么。机器人不知道。

这是每个聊天SDK机器人的默认设置。每条消息都是一张白纸。没有对过去对话的记忆，没有跨平台的意识，没有积累的知识。

团队通过手动将所有内容通过管道传输到 Jira 或 Notion 来解决这个问题。但背景——为什么提出请求、谁关心它、讨论了什么——的细微差别在交接过程中被迷失了。

​​如果机器人刚刚记住了怎么办？

## 修复：一个包装，共享记忆 {#the-fix-one-wrapper-shared-memory}

[`@vectorize-io/hindsight-chat`](https://hindsight.vectorize.io/sdks/integrations/chat) 将 `withHindsightChat()` 包装器添加到任何 Chat SDK 处理程序。它会在处理程序运行之前自动调用相关记忆，并在运行之后保留对话。

```
Slack message ─────┐
                    ├─→ withHindsightChat() ─→ recall ─→ your handler ─→ retain
Discord message ───┘                            │
                                                ▼
                                         Hindsight API
                                         (shared memory)
```

两个平台共享相同的记忆库。当有人在 Discord 中提问时，Slack 中报告的错误就会出现。两者的功能请求都会累积。随着时间的推移，机器人会积累机构知识。

核心处理程序如下所示：

```typescript
bot.onNewMention(
  withHindsightChat(
    {
      client: hindsight,
      bankId: () => 'team-memory',
      retain: { enabled: true, tags: ['chat'] },
    },
    async (thread, message, ctx) => {
      const system = [
        '您是一名团队助理，负责跟踪功能请求、错误和决策。',
        '你记得团队在 Slack 和 Discord 上讨论的所有内容。',
        ctx.memoriesAsSystemPrompt()
          ? `\nHere is what you know:\n${ctx.memoriesAsSystemPrompt()}`
          : '',
      ].join('\n');

      const { text } = await generateText({
        model: openai('gpt-4o-mini'),
        system,
        prompt: message.text,
      });

      await thread.post(text);
      await ctx.retain(`User: ${message.text}\nAssistant: ${text}`);
    }
  )
);
```

这就是整个处理程序。包装器负责回忆记忆，为 LLM 格式化它们，并保留对话。你只要写逻辑就可以了。有关所有配置选项，请参阅[完整API参考](https://hindsight.vectorize.io/sdks/integrations/chat)。

## 这在实践中是什么样子 {#what-this-looks-like-in-practice}

**周一，闲暇时间：**
> **@team-bot** 移动设备上的结账失败——用户无法在 iOS 上点击支付按钮

机器人确认并保留错误报告。

**星期二，不和谐：**
> **@team-bot**我们确实需要深色模式，本周有三位客户询问过

机器人保留功能请求。

**周三，闲暇时间：**
> **@team-bot** 本周有哪些未解决的问题？

机器人会回忆起结账错误和黑暗模式请求——即使它们来自不同的平台、不同的日期和不同的人。

没有 Jira 集成。无需手动标记。机器人只是记住了。

## 它是如何工作的 {#how-it-works}

Hindsight 不是一个简单的向量存储。当机器人保留对话时，Hindsight的管道：

1. **提取结构化事实**——“移动 iOS 上的结账被破坏”成为实体（结账、移动、iOS）和关系的事实
2. **构建知识图谱**——实体跨对话链接，因此“结帐”将错误报告与之前有关结帐流程的任何讨论联系起来
3. **多种策略回忆**——语义搜索、关键词匹配、图遍历和时间排序全部并行运行并融合结果

这意味着机器人不仅仅查找与您的查询相似的消息。它知道“未解决的问题”与错误报告和功能请求都相关，即使这两条消息都不包含“问题”一词。

## 记忆隔离 {#memory-isolation}

`bankId`选项控制谁共享记忆：

- **共享团队记忆** (`bankId: 'team-memory'`)：每个人都读取和写入同一个记忆库。适合跟踪整个团队的错误、决策和功能请求。
- **每用户记忆**（`bankId: (msg) => msg.author.userId`）：每个人都有自己的记忆库。适合记住个人喜好的私人助理。
- **每通道或每项目**：根据需要设置记忆库 ID 的范围。每个项目、每个团队、每个客户都有一个记忆库。

对于跨平台用例，共享记忆库是关键。 Slack 和 Discord 都写入同一个记忆库，因此记忆随处可用。
