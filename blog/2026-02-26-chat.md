## 问题：团队机器人什么都记不住 {#the-problem-your-team-bot-forgets-everything}

你的团队在 Slack 和 Discord 上都使用机器人。有人在 Slack 中报告了一个错误：“移动设备上的结账流程出了问题。”另一个人在 Discord 中提出了一项功能请求：“我们需要支持深色模式。”一周后，产品经理问机器人：“目前有哪些未解决的问题？”机器人一无所知。

这是所有 Chat SDK 机器人的默认情况：每条消息都像从零开始。它们记不住之前的对话，不了解其他平台上的交流，也不会积累知识。

团队只好手动把所有内容导入 Jira 或 Notion。但交接过程中，背景信息和细节都会丢失：为什么有人提出这项请求、谁在意这件事、大家讨论了什么。

如果机器人能记住这些内容呢？

---

## 解决方案：一个包装器，共享记忆 {#the-fix-one-wrapper-shared-memory}

[`@vectorize-io/hindsight-chat`](/sdks/integrations/chat) 为任何 Chat SDK 处理程序提供 `withHindsightChat()` 包装器。它会在处理程序运行前自动召回相关记忆，并在运行后存入对话。

```
Slack 消息 ─────┐
                 ├─→ withHindsightChat() ─→ 召回 ─→ 你的处理程序 ─→ 存入
Discord 消息 ───┘                         │
                                          ▼
                                   Hindsight API
                                    （共享记忆）
```

两个平台共用同一个记忆库。在 Slack 中报告的错误，会在有人通过 Discord 提问时被召回。功能请求也会在两个平台上不断积累。随着时间推移，机器人会逐渐积累团队知识。

核心处理程序如下：

```typescript
bot.onNewMention(
  withHindsightChat(
    {
      client: hindsight,
      bankId: () => 'team-memory',
      retain: { enabled: true, tags: ['chat'] },
    },
    async (thread, message, ctx) => {
      const system = [
        'You are a team assistant that tracks feature requests, bugs, and decisions.',
        'You remember everything the team has discussed across Slack and Discord.',
        ctx.memoriesAsSystemPrompt()
          ? `\nHere is what you know:\n${ctx.memoriesAsSystemPrompt()}`
          : '',
      ].join('\n');

      const { text } = await generateText({
        model: openai('gpt-4o-mini'),
        system,
        prompt: message.text,
      });

      await thread.post(text);
      await ctx.retain(`User: ${message.text}\nAssistant: ${text}`);
    }
  )
);
```

整个处理程序就是这些。包装器会负责召回记忆、将其整理成适合 LLM 使用的格式，并存入对话。你只需编写自己的业务逻辑。所有配置选项请参阅[完整 API 参考](/sdks/integrations/chat)。

## 实际效果 {#what-this-looks-like-in-practice}

**周一，Slack：**
> **@team-bot** 移动设备上的结账流程坏了——用户在 iOS 上无法点击支付按钮。

机器人确认收到，并存入这条错误报告。

**周二，Discord：**
> **@team-bot** 我们真的需要深色模式，这周已经有三位客户问过了。

机器人存入这项功能请求。

**周三，Slack：**
> **@team-bot** 这周有哪些未解决的问题？

机器人会召回结账流程错误和深色模式请求，尽管它们来自不同平台、不同日期和不同的人。

无需集成 Jira，也无需手动添加标签。机器人会自己记住这些内容。

## 工作原理 {#how-it-works}

Hindsight 并非简单的向量存储。机器人存入对话时，Hindsight 的处理流程会：

1. **提取结构化事实**：“移动设备上的 iOS 结账流程出了问题”会被提取为一条包含实体（结账流程、移动设备、iOS）和关系的事实。
2. **构建知识图谱**：实体会在不同对话之间建立关联，因此“结账流程”可以把错误报告与此前关于结账流程的讨论联系起来。
3. **采用多种策略进行检索**：语义检索、关键词匹配、图遍历和时间排序会并行运行，并融合结果。

因此，机器人不只是查找与你的查询相似的消息。它还能理解“未解决的问题”与错误报告和功能请求都有关联，即使那两条消息里都没有出现“问题”这个词。

## 记忆隔离 {#memory-isolation}

`bankId` 选项决定哪些人共享记忆：

- **共享团队记忆**（`bankId: 'team-memory'`）：所有人都从同一个记忆库读取内容并写入记忆。适合跟踪整个团队的错误、决策和功能请求。
- **每位用户各自拥有记忆**（`bankId: (msg) => msg.author.userId`）：每个人都有自己的记忆库。适合会记住个人偏好的私人助手。
- **按频道或项目划分**：可以按需设定记忆库 ID 的范围，例如每个项目、团队或客户各用一个记忆库。

对于跨平台场景，共享记忆库是关键。Slack 和 Discord 都会写入同一个记忆库，因此各个平台都能使用这些记忆。

## 支持的平台 {#supported-platforms}

Vercel Chat SDK 支持 Slack、Discord、Microsoft Teams、Google Chat、GitHub 和 Linear。`withHindsightChat()` 包装器适用于所有这些平台：代码相同、记忆相通，平台可以任意组合。
