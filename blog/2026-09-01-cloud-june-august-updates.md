距上次 Cloud 更新汇总已经三个月，而这段时间交付的工作远超三个月的分量。上次发布更新时，最新版本还是 0.6.2；本次涵盖了十三个版本：**v0.7.0 至 v0.9.2**。

最重要的新增功能是可在控制台浏览和编辑的**客户管理知识库**。此外，心智模型现在可按设定的计划刷新；星图可以全屏查看；文档支持后台导出；整个控制台也采用了全新的视觉设计。

这段时间还推出了一系列**企业版**功能：接入自有身份提供商的单点登录、组织级 MFA 强制要求、按记忆库启用的审计日志，以及能力更强的记忆防护。

## 可编辑的知识库 {#a-knowledge-base-you-can-edit}

最大的新增功能是**知识库**：一组由客户管理、与记忆并存的页面，并按照你设定的文件夹层级组织。

![Hindsight 控制平面中的知识库目录树](/img/blog/knowledge-pages-tree.webp)

先说明这里的概念变化：知识页**就是**心智模型，只是套用了更简单、文档式的配置。因此，知识页不是需要手动维护的静态文件，而是常备答案：它会在后台根据底层记忆重建，应用可以直接读取，无需在请求处理过程中承担综合生成的成本。

控制台提供：

- **文件夹树**，以层级而非平铺列表组织页面。
- **页面编辑器**，同时在旁边显示渲染后的结果。
- 覆盖知识库的**页面级搜索**。
- **目录树可见的刷新触发器**，无需打开页面就能了解其更新方式。
- **按范围判断待更新状态**：每个页面都会报告*自己的*范围内是否出现新内容，而不是继承一个会将所有页面同时标为待更新的记忆库级时间标记。

![在控制台中编辑知识页](/img/blog/knowledge-pages-edit.webp)

还有两项能力让你能在控制台之外使用知识库。`hindsight fs` 会将知识库映射到文件系统，因此可以在本地镜像页面并通过 CLI 管理。知识库的 CRUD 操作现在也通过**原生 MCP 工具**提供；连接到 Cloud 的智能体可以创建、读取、更新和搜索自己的知识库，而不再只能读取。

详细介绍见[编程智能体的知识页面](/blog/2026/08/13/knowledge-pages-coding-agents)和[通过 MCP 管理知识库](/blog/2026/08/26/knowledge-base-mcp-tools)。

## 心智模型定时刷新 {#mental-models-on-a-schedule}

[心智模型](/blog/2026/06/05/mental-models-deep-dive)新增了第三种刷新方式：除了手动刷新和出现新记忆时刷新，现在还可以**按 cron 计划刷新**。

控制台将这些方式合并到一个**刷新触发器**选项中，可选*手动*、*有新记忆时*或*按计划*。只有选择第三项时才会显示 cron 字段。计划采用标准的五字段 UTC cron 表达式，输入时会即时验证；两种自动刷新模式刻意设为互斥。

计划界面补足了这类界面常遗漏的细节：

- **实时预览**：用自然语言说明表达式的含义，并以 UTC 和本地时间列出接下来的多次运行时间。
- 模型列表、仪表盘和详情对话框在“上次刷新”旁显示**“下次刷新”**。

此外还提供：

- **刷新试运行**：生成模型但不持久化，并可选择附带执行跟踪，让你在正式提交前查看刷新会产生什么结果。这项能力目前通过 API 提供，控制台中没有对应按钮。
- 自动刷新之间的**最短间隔**，防止繁忙记忆库持续对同一个模型进行综合生成。
- **一致的待更新状态报告**：无论在哪处查看，都以相同方式计算和说明模型是否待更新，修复此前各处结果不一致的问题。

## 全新外观 {#a-new-look}

控制台的设计系统全面更新，不只是换颜色。

组件库原有的标准灰色已替换为 **Hindsight 配色**。新配色通过设计 token 应用，无需逐个修改组件，所有视图便能同时换用新外观。最明显的改进是修复了浅色模式下卡片与页面背景同色、**几乎看不见**的问题：现在页面背景为 `#F3F5F9`，卡片为白色；深色模式采用偏蓝的配色，页面背景为 `#080C17`，卡片为 `#0F1724`。

另外两项小改动也让界面更舒适，虽然用户未必能指出原因：

- **字距从 `0.025em` 调整为 `0`。** Inter 字体在正文字号下使用正字距会显得不协调。
- **两种模式的正文都满足 WCAG AA。** 次要文字色调整为 `#525866`，与页面对比度为 5.3:1，与卡片为 7.1:1。

## 动态全屏星图 {#constellation-animated-and-fullscreen}

上次更新引入的星图（Constellation）新增两项能力。

![星图视图：以交互图展示记忆和实体](/img/blog/constellation-view.webp)

- **动画和内嵌详情**：图会动态播放；点击一条记忆即可打开详情，不会跳转到其他页面。
- **全屏**：图占据整个视口，滚动缩放、拖动平移、悬停探索实体关联。

## 文档与实体 {#documents-and-entities}

数据视图的多项导航改进：

- **文档标签筛选**，各视图统一使用分面筛选标签，让筛选操作保持一致。
- **按关联实体筛选记忆**，并提供**实体时间线**，查看记忆库关于某个实体的认知如何随时间变化。
- 正在由运行中的 Retain 操作更新的文档会显示**处理中标记**。

## 导出记忆库文档 {#exporting-a-banks-documents}

可从控制台导出记忆库中的文档，处理这些文档所得的事实、实体名称、因果关联和文本分块也会一并导出。

- **后台运行。** 导出作为可跟踪操作提交，而非单次长请求；大型记忆库打包时不会持续占用连接。
- **观测可选。** 复选框用于控制是否在原始事实之外一并导出整合后的观测。

目前只有导出功能，Cloud 尚不提供对应的文档导入。

## 单点登录与 MFA {#single-sign-on-and-mfa}

需要控制访问方式的团队新增两项身份功能。

**单点登录**允许组织自带身份提供商，在设置的单点登录标签页配置一次即可：

- **OIDC 或 SAML**：支持 Okta、Entra、Google Workspace 和其他兼容标准的提供商。
- **认领邮件域名并通过 DNS 验证。** 域名验证通过且配置生效后，使用该域名邮箱登录的用户会自动转到你的 IdP，无需记住点击另一个按钮。
- **成员首次登录时自动开通账号**，并在团队列表中标记为通过 SSO 开通，因此无需提前创建账号。
- **客户端密钥静态加密**，API 从不返回密钥。

域名启用 SSO 后，该域名邮箱的密码登录和密码重置会被拒绝，无法绕开 IdP。

组织可以强制所有成员使用**多因素认证**。所有者启用*要求所有成员使用 MFA* 后，成员必须先注册认证因素，并使用该因素验证当前会话，之后才能访问。支持的因素包括**身份验证器应用（TOTP）、安全密钥和通行密钥（WebAuthn）、短信验证码及邮件验证码**。

组织未强制要求时，个人也可从账户安全页面自愿注册。设置对话框显示二维码，并为无法扫码的设备提供手动密钥。

对 HIPAA 等要求会话管理的组织，还提供**30 分钟空闲超时**，无操作后自动退出。

这两项功能都在上次汇总后不久推出，均为按组织启用的企业版功能。

## 审计日志 {#audit-logging}

审计日志会记录记忆库中发生的 Retain（存入）、Recall（召回）、Reflect（反思）及其他受审计操作，形成可查询的记录。查看器支持按操作和严重程度筛选，并用图表展示请求量随时间的变化。

日志**可按记忆库分别选择启用**，无需在整个部署中一刀切；这适合大规模部署。审计日志会产生大量数据，而且多数记忆库并不需要，因此只需在需要的记忆库的审计日志设置中开启。

这是 Cloud 企业版功能。

## 企业版记忆防护 {#memory-defense-enterprise}

记忆防护会在 Retain（存入）期间检查内容，并决定如何处理敏感密钥、提示注入和超大载荷。

所有记忆库都具备基础功能：总开关、默认动作和**密钥脱敏**，写入前将检测到的 API 密钥和令牌替换为 `[REDACTED:github_token]` 等标记。

企业版新增可独立启用和调节的检测器：

| 能力 | 检测内容 |
|---|---|
| **提示注入防护** | 向记忆注入“忽略此前指令”或覆盖系统指令等尝试 |
| **大小异常** | 占用 token、挤压排序空间并为数据外传创造条件的超大载荷；默认阈值为 64 KB |
| **受保护文档标签** | 重新提交文档时会移除或替换受保护标签的操作 |
| **广泛模式库** | 在基础检测之外增加 220 多种密钥检测模式 |
| **Base64 解码** | 解码 Base64 数据并重新扫描隐藏密钥 |
| **LLM 筛查** | 模式匹配无法捕获的自然语言形式的信息泄露，例如“密码是……” |

每种检测能力都有自己的处理动作和最低严重程度阈值，因此可以阻止高置信度检出的敏感内容，同时只标记处于边界情况的内容。功能权益由服务端和控制台共同校验；调用 API 也无法绕过权益限制来配置策略。

## 其他更新 {#also-shipped}

其他值得了解的小改动：

- **操作运行时会报告进度。** 过去，长时间运行的整合操作无论处理正常还是陷入停滞，看起来都一样。现在操作会在运行中记录粗略的阶段、已处理量和总量快照，因此可以区分只是速度较慢还是已经卡住。
- **事实提取试运行**是一个只读 API 端点，可预览 Retain 会从一段文本中提取哪些内容，而不会写入记忆库。响应包含候选事实和 token 用量，但不会执行实体消解、生成嵌入向量或进行持久化。
- **观测范围**可以枚举、筛选和可视化；对于跨越多个范围的观测，也可以使用 `shared` 关键字。
- **审计日志和观测**可以按记忆库分别覆盖设置，不再只能使用整个部署统一的设置。
