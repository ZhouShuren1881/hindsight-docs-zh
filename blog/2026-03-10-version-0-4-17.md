Hindsight 0.4.17 添加了心智模型和观察的差异视图的历史跟踪、灵活的每个请求文件解析、失败的异步操作的手动重试以及现有文档的标签管理，以及一些可靠性修复。

<!-- truncate -->

- [**历史追踪**](#history-tracking)：通过差异视图回顾心智模型和观察随着时间的推移如何变化。
- [**灵活的文件解析**](#flexible-file-parsing)：为每个请求选择一个解析器并配置文件上传的后备链。
- [**手动重试**](#manual-retry)：直接从操作视图重试失败的异步操作。
- [**标签更新**](#tag-updates)：更改或更新现有文档上的标签，而无需重新摄取它。

## 历史追踪 {#history-tracking}

心智模型和观察现在追踪它们的完整变更历史。每次Hindsight巩固新记忆并更新心智模型或观察时，都会保留之前的版本并记录差异。

控制平面 UI 通过内联差异视图公开此历史记录（绿色的添加，红色的删除），以便您可以准确地看到每个条目随着时间的推移如何演变。这对于审核系统对用户或主题的理解如何随着新内容的吸收而发生变化非常有用，并且对于在模型朝着意外方向漂移时调试集成行为非常有用。

历史记录自动跟踪，无需配置。现有的心智模型和观察将从本次发布开始积累历史。

## 灵活的文件解析 {#flexible-file-parsing}

文件上传现在可以指定在每个请求的基础上使用哪个解析器，覆盖该请求的服务器默认值。当您的文档需要特定解析器时，这非常有用 - 例如，首选 Iris 解析器来处理扫描的 PDF，而使用默认的 Office 文档。

您还可以配置**后备链**：如果主解析器失败，Hindsight将在出现错误之前按顺序尝试每个后续解析器。当解析器可用性变化或文档不可预测时，这使得摄取管道更具弹性。

```python
client.retain_file(
    bank_id="my-bank",
    file=open("report.pdf", "rb"),
    parser="iris",               #首选解析器
    parser_fallback=["default"], #如果Iris失败则恢复默认值
)
```

新的**延长钩**在文件转换为Markdown之后、文本传递到记忆存储管道之前触发。这允许扩展在任何事实提取发生之前检查或转换解析的内容 - 去除样板标头、注入元数据或重新格式化部分。

## 手动重试 {#manual-retry}

操作视图现在包含用于失败异步操作的**重试**按钮。以前，失败的记忆存储或集成需要重新提交原始请求。现在，您可以直接从 UI 触发重试，而无需任何 API 调用，这对于LLM 超时或临时网络错误等暂时性故障特别有用。

操作视图在此版本中还获得了两项生活质量改进：您现在可以**按操作类型过滤**独立地专注于保留、合并或反思，并且**自动刷新**行为更加可靠——当浏览器选项卡位于后台时，它不再停止或错过更新。

## 标签更新 {#tag-updates}

文档现在可以在摄取后更改其标签。以前，标签在记忆存储时设置一次，只能通过删除和重新摄取文档来更新。

```python
client.update_document(
    bank_id="my-bank",
    document_id="doc-abc123",
    tags=["env:prod", "project:alpha"],
)
```

标签影响检索过滤和观察范围。更新文档上的标签将反映在未来的记忆召回和集成过程中，而无需重新摄取。

## 其他更新 {#other-updates}

**改进**
- 现在可以为整合和记忆召回期间使用的“源事实”配置令牌限制，使您在使用大型记忆库时可以更好地控制上下文使用和成本。
- 记忆库选择器现在会截断下拉列表中非常长的记忆库名称，从而防止控制平面 UI 中出现布局问题。

**错误修复**
- 修复了影响多租户记忆存储 Webhook 的 Webhook 架构问题。
- 通过在保留之前从解析的文件内容中剥离空字节来修复文件摄取失败。
- 修复了使用命名`tool_choice`时OpenAI兼容提供程序的工具选择处理。
- 改进的整合行为，将记忆库的任务优先于短暂状态启发式。
- 修复了数据库迁移，以正确处理心智模型嵌入维度更改。
- 修复了 Iris 解析器 httpx 读取超时导致的文件上传失败问题。
- 通过在进程中序列化 Alembic 升级来提高运行迁移的可靠性。
- 修复了 Google 使用工作负载身份联合凭据时的云存储身份验证。
- ​​修复了记忆库选择器在打开下拉菜单时刷新记忆库列表的问题。
