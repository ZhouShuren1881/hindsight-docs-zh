Hindsight 0.4.17 新增了心智模型和观测的历史记录与差异视图、灵活的逐请求文件解析、失败异步操作的手动重试，以及对现有文档的标签管理，并修复了若干可靠性问题。

<!-- truncate -->

- [**历史记录**](#history-tracking)：通过差异视图查看心智模型和观测随时间发生的变化。
- [**灵活的文件解析**](#flexible-file-parsing)：为每个请求选择解析器，并为文件上传配置回退链。
- [**手动重试**](#manual-retry)：直接在操作视图中重试失败的异步操作。
- [**标签更新**](#tag-updates)：更改或更新现有文档的标签，无需重新摄取。

## 历史记录 {#history-tracking}

现在，心智模型和观测都会记录完整的变更历史。每当 Hindsight 整合新记忆并更新心智模型或观测时，都会保留先前版本并记录差异。

控制台 UI 会通过内联差异视图展示历史记录，新增内容以绿色标出，删除内容以红色标出，因此你可以准确查看每个条目随时间如何演变。随着新内容被摄取，系统对用户或主题的理解可能发生变化；这项功能便于审查这些变化，也有助于在模型意外偏移时调试整合行为。

历史记录会自动跟踪，无需配置。自此版本发布起，现有心智模型和观测也会逐步积累历史记录。

## 灵活的文件解析 {#flexible-file-parsing}

现在，文件上传请求可以指定所用的解析器，并覆盖该请求的服务器默认设置。如果某些文档需要特定解析器，这项功能就很有用；例如，扫描版 PDF 可以优先使用 Iris 解析器，而 Office 文档使用默认解析器。

你还可以配置**回退链**：如果主解析器失败，Hindsight 会按顺序尝试后续解析器，然后才返回错误。解析器可用性不稳定或文档难以预料时，这能让摄取流水线更可靠。

```python
client.retain_file(
    bank_id="my-bank",
    file=open("report.pdf", "rb"),
    parser="iris",               # 优先使用的解析器
    parser_fallback=["default"], # Iris 失败时回退到默认解析器
)
```

新增的**扩展钩子**会在文件转换为 Markdown 之后、文本传入 Retain 流程之前触发。这样，扩展就能在提取事实之前检查或转换解析后的内容，例如删除模板化页眉、注入元数据或重新排版章节。

## 手动重试 {#manual-retry}

现在，操作视图会为失败的异步操作显示**重试**按钮。以前，Retain 或整合失败后必须重新提交原始请求。现在，你可以直接在 UI 中触发重试，无需调用 API；对于 LLM 超时或临时网络错误等短暂故障，这尤其有用。

此版本还为操作视图带来了两项易用性改进：现在可以**按操作类型筛选**，分别查看存入、整合或反思操作；此外，**自动刷新**更加可靠，即使浏览器标签页处于后台，也不会停止或漏掉更新。

## 标签更新 {#tag-updates}

现在，文档摄取后也可以更改标签。以前，标签在 Retain 时设置，此后只有删除并重新摄取文档才能更新。

```python
client.update_document(
    bank_id="my-bank",
    document_id="doc-abc123",
    tags=["env:prod", "project:alpha"],
)
```

标签会影响检索筛选和观测范围。更新文档标签后，后续的 Recall 和整合过程都会采用新标签，无需重新摄取。

## 其他更新 {#other-updates}

**改进**
- 现在可以配置整合和 Recall 过程中所用“来源事实”的 token 限制；处理大型记忆库时，你可以更精细地控制上下文用量和成本。
- 记忆库选择器现在会截断下拉菜单中过长的记忆库名称，避免控制台 UI 出现布局问题。

**错误修复**
- 修复了影响多租户 Retain Webhook 的 Webhook 模式问题。
- 修复了文件摄取失败问题：在 Retain 前从解析后的文件内容中移除空字节。
- 修复了使用命名 `tool_choice` 时，OpenAI 兼容服务提供方的工具选择处理问题。
- 改进了整合行为，使记忆库的任务说明优先于临时状态启发式判断。
- 修复了数据库迁移未能正确处理心智模型嵌入维度变更的问题。
- 修复了 Iris 解析器发生 httpx 读取超时所导致的文件上传失败。
- 通过在进程内串行执行 Alembic 升级，提高了运行迁移的可靠性。
- 修复了使用 Workload Identity Federation 凭据时 Google Cloud Storage 身份认证失败的问题。
- 修复了打开下拉菜单时，记忆库选择器未刷新记忆库列表的问题。
