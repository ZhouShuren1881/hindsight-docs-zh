# Hindsight 是有史以来增长最快的开源AI 记忆项目 {#hindsight-is-the-fastest-growing-open-source-ai-memory-project-ever}

Hindsight——能够学习的智能体记忆——是有史以来增长最快的开源智能体记忆项目。这篇文章列出了证据：我们自己对 GitHub 每颗恒星的数据进行的分析，以及来自与该主张没有利害关系的两个第三方的独立确认。

首先，解释为什么“增长最快”比听起来更难证明——因为最明显的衡量方法也是最具误导性的。

<!-- truncate -->

去寻找 GitHub 上的 AI 记忆项目，你会发现一个 *出现* 高于其他一切：超过 50,000 颗星星，大约两个月内积累。案件结案了吗？不完全是。 GitHub 记录了每颗星星的时间戳，当你拉动它们时，该项目的故事就崩溃了。它的大部分明星——数以万计——在存储库创建后几天内就到达了，包括**单日超过16,000**，当时它还没有任何观众。真正的项目不会这样发展。事实证明，星星是可以购买的，而在全新的回购协议上，星星的垂直墙正是购买的样子。

因此，仅原始计数并不能证明什么。为了诚实地提出这一主张，我们需要采取措施，让真正的开发人员做出真正的选择——而这正是我们应用的每一项措施中坚持的原则。

## ​​从简单开始：谁获得星星最快？ {#start-simple-who-gains-stars-fastest}

最简单的诚实衡量标准是总星星数除以项目存在的时间。以下是每个主要的开源智能体记忆项目（合法增长的项目）的数量。

|项目|星星|年龄|星星/天（一生平均）|
|---|---:|---:|---:|
|**Hindsight**|**16,035**|**7.3 个月**|**72.2**|
|记忆0|58,168|35.6 个月|53.6|
|石墨|27,213|22.0 个月|40.7|
|超级记忆力|26,303|27.3 个月|31.6|
|莱塔 / MemGPT|23,226|31.9 个月|23.9|
|科尼|17,740|33.7 个月|17.3|
|记忆库|2,747|21.2 个月|4.3|
|泽普|4,654|37.4 个月|4.1|

Hindsight 拥有该类别中最高的恒星速度 — 领先于 Mem0，后者后来成为 GitHub 上最大的智能体记忆项目，并且是 Supermemory 速度的两倍多。而且它在做到这一点的同时，比清单上的其他所有东西都**年轻三到五倍**。这是一个有希望的第一个答案。但这还不是一个谨慎的事情。

## 更难的问题：我们的比较公平吗？ {#the-harder-question-are-we-comparing-fairly}

一生的平均水平可以让一个年轻的项目变得更加美好。病毒库往往会在早期的爆发中赢得大部分明星，然后就开始下滑，因此一个持续三年左右的项目会拖着一条长而缓慢的尾巴，拖累其平均水平。将 Hindsight 的七个炎热月份与 Mem0 的三年平均值进行比较，您可能会将短跑与马拉松的配速进行比较——这两个方向都不是公平的较量。

解决这个问题的诚实方法是在其生命周期的*同上*点比较每个项目。与曝光购买明星项目相同的每颗星时间戳让我们能够准确地重建每个项目在今天Hindsight的年龄（222天）时拥有多少颗星。

|项目|第 222 天的星星|今天的明星|
|---|---:|---:|
|**Hindsight**|**16,035**|16,035|
|莱塔 / MemGPT|9,696|23,226|
|记忆0|6,942|58,168|
|超级记忆力|6,389|26,303|
|石墨|2,383|27,213|
|泽普|1,505|4,654|
|科尼|344|17,740|

这就是答案的尖锐之处。在同一年龄，Hindsight还有**1.6× 第二快项目的明星**（Letta，以病毒性 MemGPT 的形式推出）和**2.3×Mem0**。 Mem0 最终达到了 57,000 颗星，但在 Hindsight 今天所处的七个月大关上，它的星数还不到 7,000 颗。该类别中的每个项目在这个年龄段的受众都比 Hindsight 现在要少。平均水平之下没有隐藏的早期峰值。这是 *是* 的峰值 - 这是该类别通过实际采用而产生的最大峰值。

很容易假设Hindsight只是在最后几周勉强领先。逐月的数字却恰恰相反。以下是每个项目自其存储库创建之日起每隔 30 天的累积星级数。

Hindsight从第一天起就没有领先——这是整张照片中最令人鼓舞的部分。在最初的四个月里，它处于休眠状态，星数低于 2,000，而 Letta 和 Mem0 则舒适地坐在前面。然后，在第 120 天到第 222 天之间，它增加了超过 **100天内获得14,000颗星** — 持续运行大约 **高峰时期每天150颗星**。这是该类别有史以来最陡峭的有机增长，而且曲线并没有回落。虽然其竞争对手在这个年龄已经趋于平缓，但Hindsight仍在攀升。

并注意*形状*中的对比。被收购的明星项目在第一周就增长了一堵垂直墙。 Hindsight 是一个长达数月的斜坡，随着越来越多的人使用它，它会变得更加陡峭 - 这是真实口碑的标志，而不是一次性交易。这种拐点随着生产部署开始工作、集成生态系统填充以及[BEAM 基准测试结果](https://hindsight.vectorize.io/blog/2026/04/02/beam-sota)的那一刻而发生，这让团队有理由相信智能体记忆足以在此基础上进行构建。人们并没有在发布日的炒作中明星Hindsight。他们在使用后给它加了星标。

## 我们如何衡量这一点 {#how-we-measured-this}

所以你可以重现它：

**数据源。** GitHub 的观星者 API 返回每颗恒星的时间戳 (`Accept: application/vnd.github.star+json`)。我们按照从旧到新的顺序对每个存储库的观星者进行了寻呼，并统计了在存储库创建后的前 222 天内有多少人跌倒。于 2026 年 6 月 9 日拉取。合法增长的存储库均未达到 API 的分页上限，因此它们的早期窗口计数已完成。 （对于购买明星项目，上限本身就是说明：所有 40,000 个可回收的明星都在第一周内掉落。）

​​**为什么是222天。** 这是 Hindsight 在撰写本文时的确切年龄（存储库创建于 2025 年 10 月 30 日）。其他所有项目都是根据其创建之日起的相同 222 天窗口进行衡量。

**项目比较。** 我们能找到的最著名的开源智能体记忆项目：Mem0、Letta/MemGPT、Supermemory、Graphiti、Zep、Cognee 和 Memobase。我们排除了任何其明星历史显示非有机批量收购的项目——一旦你有了时间戳，单个日期数以万计的明星就很容易被发现，而且我们衡量的是真正的开发者兴趣，而不是你可以购买的明星。如果我们错过了一个在七个半月内达到约 16,000 颗星的合法项目，我们想知道 - 展开讨论，我们将更新这篇文章。

一些值得命名的细节。 Mem0 的存储库在重命名之前以 *Embedchain* 开始使用，因此它的前 222 天在一定程度上是对不同项目的早期受众的期待——这只会让 Mem0 的数字更加美好，而 Hindsight 仍然领先 2.3 倍。 Letta 的存储库最初是 *MemGPT*，发布后迅速传播，使其成为列表中最强的诚实比较； Hindsight 仍然比第 222 天的计数高出 1.6 倍。 Supermemory 实际上并不像 Hindsight 那样开源——它的核心产品是封闭的，公共存储库是专有服务的伴侣。我们将其纳入其中，是因为它的星级仍然是开发人员对该产品兴趣的有意义的代表，但值得明确的是，这不是同类的开源比较：Hindsight的星级衡量的是您运行的实际事物的采用率，而不是对其背后的封闭系统的兴趣。

关于明星的含义和含义的最后一点：它们衡量的是思想份额和势头，而不是收入或生产使用情况。这是一种增长主张。有关收养故事，请参阅[万星回顾展](https://hindsight.vectorize.io/blog/2026/04/22/hindsight-10k-stars)。

## 这不只是我们这么说 {#it-isnt-just-us-saying-it}

我们在这一主张中有着明显的利害关系，所以最重要的部分是两个独立的第三方——我们都无法控制——落在了同一个地方。

**OSSCAR 将 Vectorize 列为增长最快的前 10 名开源组织。** [OSSCAR](https://osscar.dev/)是增长最快的开源组织的季度排名，由**Supabase 和>提交**，综合增长得分GitHub明星、贡献者和软件包下载。在 2026 年第一季度的“扩展”层中，**vectorize-io 排名第 10**- 他们评估了数以万计的组织，涵盖各个软件类别，而不仅仅是记忆。而其中的奉献者AI- 记忆项目，这是板上排名最高的项目：**Mem0 位于#22**，Supermemory、Letta、Zep 和 Cognee 完全缺席该级别的前 25 名。 > 提交团队[直接喊出来](https://x.com/commitvc/status/2056707157840588950): *“#10 Vectorize 的 Hindsight 是一种能够学习的智能体记忆：自适应记忆基础设施，随着每次智能体交互而变得更加智能。”*

**一家安全公司发现 Vectorize 是实际部署中排名第一的 MCP 服务器。**我们最喜欢这项证据，因为它衡量实际部署，而非星数。安全公司 **dope.security** 在报告[*“MCP 服务器成为新的影子 IT：藏在眼前的 56 个常见域名”*](https://dope.security/post/mcp-servers-new-shadow-it-56-domains-hiding-in-plain-sight)中分析约 10,000 台设备的企业网络流量，了解人们实际连接哪些模型上下文协议服务器。前十名依次为：**1. Vectorize**、2. Anthropic、3. Atlassian、4. Zapier、5. Context7、6. Granola、7. Microsoft 365、8. Slack、9. Google Workspace、10. VS Code（[LinkedIn 摘要](https://www.linkedin.com/posts/kunala_mcp-servers-are-the-new-shadow-it-56-common-share-7454629357601525760-3AEf)）。在真实生产环境中，Hindsight MCP 服务器的使用排名高于 Anthropic、Slack 和 Google Workspace。星数衡量兴趣，这项研究衡量使用，两者指向相同结论。

## 判决 {#the-verdict}

无论从哪方面衡量，Hindsight都是有史以来增长最快的开源智能体记忆项目。按生命周期平均数计算，它获得星星的速度比其他任何系统都快；七个月大时，它拥有的恒星数量比任何同龄的恒星都多；它是生命中唯一一个在此时仍在加速而不是趋于平缓的粒子；独立的跨行业排名使其领先于所有其他记忆项目；一家安全公司的流量扫描发现其 MCP 服务器的部署比其他任何公司都更广泛。 *出现* 在原始计数上击败它的一个项目购买了该数字，时间戳证明了这一点。

所有这些都与最大的项目不同——Mem0、Graphiti、Supermemory 和 Letta 如今都更大，而且它们都是很好的项目。这是关于轨迹的陈述。但轨迹告诉你一个类别的发展方向，而现在它正朝着可学习的智能体记忆方向发展。

## 为什么会发生 {#why-it-happened}

快速增长是一种症状，而不是原因。有几件事推动了它：

- **真正学习的记忆。** 这就是Hindsight背后的整个想法——学习的智能体记忆。它不仅存储和检索文本；还存储和检索文本。它提取事实，解析实体，并随着时间的推移将它们整合到更高级别的心智模型中，因此智能体使用得越多，就会变得越敏锐，而不是仅仅积累更大的历史堆来进行搜索。
- **您可以验证的准确性。**Hindsight在[BEAM](https://hindsight.vectorize.io/blog/2026/04/02/beam-sota)（“超越一百万token”）上排名第一——在惩罚性的 1000 万token级别上为 64.1%，而次优系统为 40.6%——而且不同寻常的是，随着规模的增长而不是崩溃，它的准确性*坚持下去*。这是切换的具体原因：一个您可以信任的记忆系统，其规模与真正的智能体实际达到的规模相同。
- **MIT 许可且可自行托管。** 没有供应商锁定，没有封闭的黑匣子。金融科技、医疗保健和企业团队可以在自己的基础设施上运行它。
- **真正的集成生态系统。**Claude Code、LangGraph、CrewAI、Pydantic AI、Agno、Strands等等——采用Hindsight很少意味着重新架构你的堆栈。
- **露天建造。** 提交错误、进行讨论、以稳定的节奏发布修复。当社区认为该项目值得押注时，曲线就会向上弯曲。
