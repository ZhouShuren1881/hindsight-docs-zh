# Hindsight 是有史以来增长最快的开源 AI 记忆项目 {#hindsight-is-the-fastest-growing-open-source-ai-memory-project-ever}

Hindsight——能够学习的智能体记忆——是有史以来增长最快的开源智能体记忆项目。本文列出相关证据：我们对 GitHub 每个星标的时间数据所做的分析，以及两个与这一主张没有利害关系的第三方提供的独立验证。

先说说为什么“增长最快”比听起来更难证明：最显而易见的衡量方法，也恰恰最容易误导人。

<!-- truncate -->

在 GitHub 上搜索 AI 记忆项目，你会发现有个项目看起来远超其他项目：短短约两个月就积累了超过 50,000 个星标。可以定论了吗？还不能。GitHub 会记录每个星标的时间戳。把这些数据取出来后，这个项目的故事就站不住脚了。它的大部分星标——数以万计——都在仓库创建后的几天内出现，其中**有一天就超过 16,000 个**，而当时它还没有任何受众。真正的项目不会这样增长。事实证明，星标可以买到；在一个新建仓库上突然出现一堵垂直的星标墙，正是购买星标的样子。

因此，单看总数说明不了什么。要诚实地提出这个主张，我们需要衡量真正的开发者作出真实选择后留下的痕迹——而我们采用的每一种衡量方法都经得起检验。

## 从简单问题开始：谁获得星标最快？ {#start-simple-who-gains-stars-fastest}

最简单而可靠的衡量方法，是用星标总数除以项目存在的时间。下表列出了主要的开源智能体记忆项目中那些确实靠自然增长获得星标的项目，以及这一比值。

| 项目 | 星标数 | 项目年龄 | 星标/天（生命周期平均值） |
|---|---:|---:|---:|
| **Hindsight** | **16,035** | **7.3 个月** | **72.2** |
| Mem0 | 58,168 | 35.6 个月 | 53.6 |
| Graphiti | 27,213 | 22.0 个月 | 40.7 |
| Supermemory | 26,303 | 27.3 个月 | 31.6 |
| Letta / MemGPT | 23,226 | 31.9 个月 | 23.9 |
| Cognee | 17,740 | 33.7 个月 | 17.3 |
| Memobase | 2,747 | 21.2 个月 | 4.3 |
| Zep | 4,654 | 37.4 个月 | 4.1 |

Hindsight 在该类别中星标增长速度最快，超过了 Mem0（它后来成为 GitHub 上最大的智能体记忆项目），速度也超过 Supermemory 的两倍。而且，Hindsight 的年龄只有表中其他项目的**三分之一到五分之一**。这是个很有希望的初步答案，但还不够严谨。

## 更难的问题：比较公平吗？ {#the-harder-question-are-we-comparing-fairly}

生命周期平均值可能让年轻项目显得更出色。病毒式传播的仓库往往在早期就获得大部分星标，随后趋于平缓；一个存在三年的项目，较长而缓慢的尾段会拉低平均值。把 Hindsight 快速增长的七个月和 Mem0 三年的平均水平相比，可能相当于拿短跑选手和马拉松选手的配速比——无论从哪个方向看，都不公平。

要公正地回答这个问题，就应该比较每个项目在生命周期同一阶段的表现。正是那些揭示了购买星标项目问题的逐个星标时间戳，让我们能还原每个项目在 Hindsight 如今这个年龄（222 天）时拥有多少星标。

| 项目 | 第 222 天的星标数 | 当前星标数 |
|---|---:|---:|
| **Hindsight** | **16,035** | 16,035 |
| Letta / MemGPT | 9,696 | 23,226 |
| Mem0 | 6,942 | 58,168 |
| Supermemory | 6,389 | 26,303 |
| Graphiti | 2,383 | 27,213 |
| Zep | 1,505 | 4,654 |
| Cognee | 344 | 17,740 |

这样一来，答案就更清楚了。在同一年龄时，Hindsight 的星标数是第二快的项目 Letta（它以病毒式传播的 MemGPT 之名发布）的 **1.6 倍**，也是 **Mem0 的 2.3 倍**。Mem0 最终达到 57,000 个星标，但在 Hindsight 如今所处的七个月节点，它还不到 7,000 个。该类别中的每个项目在这个年龄时的受众都比 Hindsight 现在小。平均值下面没有被掩盖的早期峰值。这段增长本身就是峰值，而且是该类别通过真实采用所创造的最大峰值。

## 项目仍在加速增长，没有趋于平缓 {#a-project-still-accelerating-not-coasting}

人们很容易以为 Hindsight 只是在最后几周勉强超过其他项目，但逐月数据恰恰说明情况相反。下表列出每个项目从仓库创建之日起，每隔 30 天的累计星标数。

| 天数 | 30 | 60 | 90 | 120 | 150 | 180 | 210 | 222 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **Hindsight** | 2 | 842 | 1,191 | 1,921 | 6,426 | 11,175 | 15,042 | 16,035 |
| Letta / MemGPT | 5,618 | 6,344 | 6,814 | 7,350 | 7,652 | 8,051 | 9,277 | 9,696 |
| Mem0 | 3,382 | 3,662 | 4,761 | 5,293 | 5,591 | 5,779 | 6,723 | 6,942 |
| Supermemory | 0 | 2,296 | 2,738 | 2,949 | 3,853 | 5,218 | 6,181 | 6,389 |

Hindsight 从第一天起就没有领先——而这恰恰是整幅图景中最令人振奋的部分。头四个月里，它还默默无闻，星标数不到 2,000；Letta 和 Mem0 则稳稳领先。随后，从第 120 天到第 222 天，它在约 **100 天内新增了 14,000 多个星标，在增长高峰期持续达到每天约 150 个星标**。这是该类别有记录以来最陡峭的一段自然增长，曲线也没有再次变缓。当竞争对手在同一年龄时早已趋于平缓，Hindsight 仍在攀升。

还要注意增长形态的差异。购买星标的项目在第一周就形成一道垂直的增长墙。Hindsight 的增长则持续了数月，并随着使用者增加而越来越快——这是真实口碑传播的特征，不是一次性交易。这一拐点出现在生产部署开始顺利运行、集成生态逐渐完善，以及 [BEAM 基准测试结果](/blog/2026/04/02/beam-sota)让团队有理由相信智能体记忆、并以此为基础构建系统之时。人们不是因为发布日的热度给 Hindsight 点星标，而是在使用之后才点的。

从绝对时间尺度看，这幅图景最为鲜明。Hindsight 是右下角的红线，几乎垂直地攀升至 16,000 个星标；这是图中最陡的斜率，而每个更早出现、规模更大的项目都在缓慢增长：

## 我们如何进行衡量 {#how-we-measured-this}

以下是复现方法：

**数据来源。** GitHub 的 stargazers API 会返回每个星标的时间戳（`Accept: application/vnd.github.star+json`）。我们按从早到晚的顺序分页获取每个仓库的 stargazers，并统计仓库创建后最初 222 天内获得的星标数。数据于 2026 年 6 月 9 日获取。靠自然增长的仓库都没有触及 API 的分页上限，因此它们在早期窗口内的计数是完整的。（对于购买星标的项目，分页上限本身就是线索：所有可获取的 40,000 个星标都集中在第一周。）

**为什么是 222 天。** 这是本文撰写时 Hindsight 的准确年龄（仓库创建于 2025 年 10 月 30 日）。其他每个项目也都从各自的创建日期开始，按同样的 222 天窗口衡量。

**比较对象。** 我们能找到的知名开源智能体记忆项目包括 Mem0、Letta/MemGPT、Supermemory、Graphiti、Zep、Cognee 和 Memobase。我们排除了星标历史显示有非自然批量增长的项目——只要有时间戳，单日增加数万个星标就很容易发现。我们衡量的是开发者的真实兴趣，而不是能买来的星标。如果我们漏掉了某个靠自然增长、在不到七个半月内达到约 16,000 个星标的项目，请发起讨论告诉我们，我们会更新本文。

还有几项值得说明的细节。Mem0 的仓库在重命名之前叫 *embedchain*，因此其最初 222 天的数字有一部分反映了另一个项目的早期受众；这只会让 Mem0 的数字更高，而 Hindsight 仍领先 2.3 倍。Letta 的仓库最初叫 *MemGPT*，发布后曾病毒式传播，因此它是表中最有力且公平的比较对象；Hindsight 的第 222 天星标数仍是它的 1.6 倍。Supermemory 实际上并不像 Hindsight 那样开源：它的核心产品是闭源的，公开仓库只是专有服务的配套项目。我们将其列入比较，是因为它的星标仍能有效反映开发者对该产品的兴趣；但需要说清楚，这不是同类开源项目之间的直接比较：Hindsight 的星标衡量的是人们对可自行运行的产品的采用，而非对一个闭源系统的兴趣。

最后说明星标能代表什么、不能代表什么：它衡量的是关注度和发展势头，不是收入或生产环境中的使用情况。本文提出的是增长主张。要了解采用情况，请参阅[一万星回顾](/blog/2026/04/22/hindsight-10k-stars)。

## 这不只是我们自己这么说 {#it-isnt-just-us-saying-it}

我们显然对这一主张有利害关系，因此最重要的是，两个我们无法控制的独立第三方得出了相同结论。

**OSSCAR 将 Vectorize 列为增长最快的开源组织前十名。** [OSSCAR](https://osscar.dev/) 是开源组织增长速度的季度排名，由 **Supabase 和 >commit** 制作，根据 GitHub 星标数、贡献者数量和软件包下载量的综合增长评分。在 2026 年第一季度的“Scaling”梯队中，**vectorize-io 排名第 10**；他们评估了涵盖所有软件类别的数万个组织，并非只看记忆项目。在专门从事 AI 记忆的项目中，它是榜单上排名最高的一个：**Mem0 排名第 22**，Supermemory、Letta、Zep 和 Cognee 均未进入该梯队前 25 名。>commit 团队[直接点名了它](https://x.com/commitvc/status/2056707157840588950)：*“#10 Vectorize 的 Hindsight 是能够学习的智能体记忆：自适应记忆基础设施，会随着每次智能体交互变得更聪明。”*

**一家安全公司发现，Vectorize 是真实环境中排名第一的 MCP 服务器。** 这是我们最看重的一项证据，因为它衡量的是真实部署，而不是星标。在报告[*《MCP 服务器成为新的影子 IT：我们发现的 56 个常见隐蔽域名》*](https://dope.security/post/mcp-servers-new-shadow-it-56-domains-hiding-in-plain-sight)中，安全公司 **dope.security** 扫描了约 10,000 台设备的企业网络流量，以了解人们实际连接了哪些模型上下文协议服务器。前十名依次是：**1. Vectorize**、2. Anthropic、3. Atlassian、4. Zapier、5. Context7、6. Granola、7. Microsoft 365、8. Slack、9. Google Workspace、10. VS Code（[LinkedIn 上的摘要](https://www.linkedin.com/posts/kunala_mcp-servers-are-the-new-shadow-it-56-common-share-7454629357601525760-3AEf)）。在真实生产环境中，Hindsight 的 MCP 服务器部署范围超过 Anthropic、Slack 和 Google Workspace。星标衡量兴趣，这份报告衡量使用；两者指向同一个方向。

## 结论 {#the-verdict}

按照各种可靠的衡量方法，Hindsight 都是有史以来增长最快的开源智能体记忆项目。按生命周期平均值计算，它获得星标的速度超过其他任何项目；在七个月大时，它的星标数就超过其他项目在同龄时的数量；在生命周期的这一阶段，只有它还在加速增长，而其他项目都已趋于平缓；一项独立的跨行业排名将它排在所有其他记忆项目之前；一家安全公司的流量扫描发现，它的 MCP 服务器部署范围比其他任何服务器都广。那个看起来总数超过它的项目，是靠购买星标堆高数字的，时间戳证明了这一点。

这些都不意味着它现在规模最大——Mem0、Graphiti、Supermemory 和 Letta 目前都更大，而且它们都是很好的项目。本文讨论的是发展轨迹。但轨迹能告诉你一个类别正走向何处，而眼下，它正走向能够学习的智能体记忆。

## 为什么会这样 {#why-it-happened}

快速增长是结果，不是原因。推动增长的因素有几个：

- **真正能够学习的记忆。** 这是 Hindsight 的核心理念——能够学习的智能体记忆。它不只存储和检索文本，还会提取事实、解析实体，并随着时间推移将信息整合成更高层次的心智模型。因此，智能体用得越多，能力就越强，而不是只积累更多待搜索的历史记录。
- **可以验证的准确性。** Hindsight 在 [BEAM](/blog/2026/04/02/beam-sota)（“Beyond a Million Tokens”）中排名第一：在难度极高的 10M-token 档位达到 64.1%，而第二名系统为 40.6%。更难得的是，规模扩大时它的准确性仍能保持，而不是急剧下降。这为切换系统提供了具体理由：真实智能体在实际运行中会遇到这样的规模，而你可以信任这个记忆系统。
- **采用 MIT 许可证，可自行托管。** 没有供应商锁定，也没有封闭的黑箱。金融科技、医疗保健和企业团队可以在自己的基础设施上运行它。
- **完善的集成生态。** Claude Code、LangGraph、CrewAI、Pydantic AI、Agno、Strands 等等——采用 Hindsight 通常不需要重新设计你的技术栈。
- **公开协作开发。** 用户提交 bug、参与讨论，团队持续发布修复。当社区决定值得押注这个项目时，增长曲线就开始向上弯曲。

## 亲自试用 {#try-it-yourself}

了解为什么 16,000 名开发者感到兴奋，最快的方法就是运行它：

```bash
export OPENAI_API_KEY=sk-xxx
docker run --rm -it --pull always -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY \
  -v $HOME/.hindsight-docker:/home/hindsight/.pg0 \
  ghcr.io/vectorize-io/hindsight:latest
```

API 地址为 `http://localhost:8888`，Web UI 地址为 `http://localhost:9999`。将它连接到你的智能体框架，就可以开始从对话中提取事实。

- **给[仓库](https://github.com/vectorize-io/hindsight)点星标**——靠真实使用获得的那种星标——并和我们一起看看下一个里程碑会多快到来。
- **试用 [Hindsight Cloud](https://ui.hindsight.vectorize.io)**——托管服务，可扩展，按使用量计费。
- **加入讨论**——前往 [GitHub Discussions](https://github.com/vectorize-io/hindsight/discussions) 或 [Slack](https://vectorize.io/slack)。

七个月，从 2 个星标增长到 16,000 个——每一个都靠实力赢得，为的都是能够学习的智能体记忆。感谢你和我们一起构建；让我们看看增长曲线接下来会走向何处。
