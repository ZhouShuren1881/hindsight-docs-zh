Hindsight 0.5.1 是一个抛光版本，专注于 CLI 以及记忆存储、记忆感知和嵌入式守护进程的可靠性修复。它还引入了用于自托管部署的 Cloudflare OAuth 代理、作为重排序器提供商的 SiliconFlow、在创建记忆库时应用的默认记忆库模板以及新的 `@vectorize-io/hindsight-all` 守护程序生命周期包。

<!-- truncate -->

- [**CLI 覆盖范围**](#cli-coverage)：现在可以从 `hindsight` 访问每个 OpenAPI 端点和请求正文参数。
- [**Cloudflare OAuth 代理**](#cloudflare-oauth-proxy)：自托管Hindsight的嵌入式 OAuth 前门。
- [**默认记忆库模板**](#default-bank-template)：通过单个环境变量将模板清单应用到每个新创建的记忆库。
- [**SiliconFlow重排序器**](#siliconflow-reranker)：新的重排序器提供商选项。
- [**守护进程生命周期包**](#daemon-lifecycle-package)：`@vectorize-io/hindsight-all`用于编程守护进程启动/停止。
- [**可靠性修复**](#reliability-fixes)：记忆召回、记忆存储、集成工作人员和嵌入式守护程序修复。

## CLI 覆盖范围 {#cli-coverage}

`hindsight` CLI 已扩展为涵盖 OpenAPI 规范中的每个端点，包括每个请求主体参数 — 对于 CLI 尚未实现的操作，不再需要下降到 `curl`。 Webhook、审计、操作和记忆历史子命令现已完整记录。

错误输出也更容易调试：API错误现在显示在HTTP响应正文中，并且`memory list`命令正确标记事实类型，而不是为每行显示`[UNKNOWN]`。

## Cloudflare OAuth 代理 {#cloudflare-oauth-proxy}

自托管Hindsight部署通常需要在API前面使用OAuth，而不运行完整的身份提供商。新的 Cloudflare OAuth 代理是位于 Hindsight 前面的 Cloudflare Worker，处理 OAuth 握手并向下游转发经过身份验证的请求。它附带测试、CI 和安全强化，旨在作为已经使用 Cloudflare 作为其优势的团队的直接选项。

## 默认记忆库模板 {#default-bank-template}

新的`HINDSIGHT_API_DEFAULT_BANK_TEMPLATE`环境变量将模板清单应用于每个新创建的记忆库。这使得在整个部署中标准化记忆库配置（记忆存储任务、观察、心智模型、指令）变得很容易，而无需触及应用程序代码或后配置挂钩。

​​将其与 0.5.0 中引入的记忆库模板中心配对，导出已知良好的记忆库一次，并使每个新的记忆库都具有相同的基线。

## SiliconFlow重排序器 {#siliconflow-reranker}

SiliconFlow 现在与现有选项一起成为受支持的重排序器提供商，为自托管和成本敏感的部署提供了另一个托管重排序器可供选择。像任何其他提供商一样通过 `HINDSIGHT_API_RERANKER_PROVIDER` 配置它。

## 守护进程生命周期包 {#daemon-lifecycle-package}

`@vectorize-io/hindsight-all` 是一个新的 npm 软件包，用于管理一体化守护进程的生命周期——启动、停止、运行状况检查——因此基于节点的应用程序可以在本地启动和关闭 Hindsight，而无需退出。对于每次运行都需要新的 Hindsight 实例的本地开发、嵌入式部署和测试工具很有用。

## 可靠性修复 {#reliability-fixes}

一系列修复解决了生产中发现的边缘情况：

- **记忆召回RRF排名。** 当重排序器配置为直通时，RRF 排序现在会端到端保留，而不是默默地替换。
- **异步查询嵌入。** 记忆召回现在使用异步批处理嵌入路径进行查询，消除了事件循环上的阻塞调用。
- **​​幂等记忆存储块插入。** 块插入不再重试完整性错误，消除了并发记忆存储下的一类重复插入循环。
- **ANN 交易中的种子。** 记忆存储 ANN 种子临时表现在在其事务内创建，修复了并发负载下间歇性的“关系不存在”。
- **整合老虎机记账。** 工作线程现在在配置的 `max_slots` 内预留整合槽，而不是偶尔超出它。
- **嵌入式守护进程生命周期。** 守护进程启动和停止现在已序列化，以便启动一个新实例不再会杀死一个正常的请求。
- **macOS 本地嵌入/重排序器。** 本地嵌入和重排序器的 macOS `FORCE_CPU` 默认值已恢复。
在回归导致 GPU 初始化在某些 Apple Silicon 设置上失败后，本地嵌入和重排序器的默认值已恢复。
- **重排序器错误浮现。** 重排序器初始化现在会显示真正的导入错误而不是一般故障，并围绕 jina-mlx 路径中的 Transformers 5.x 竞赛进行工作。
- **推理模型和 Azure OpenAI。** LLM 调用现在发送 `max_completion_tokens`（而不是`max_tokens`）用于推理模型和 Azure OpenAI，修复了最近的 OpenAI 推理系列模型的请求失败。
- **对次召回进行计费。** 由梦想发出的内部记忆召回呼叫现在被标记为内部，因此它们不会针对呼叫者的使用情况重复计费。

## 文档 {#documentation}

- 心智模型标签过滤现在澄清了标签过滤刷新期间使用的源记忆。
- 审计日志记录明确记录为默认关闭。
- 记忆存储`update_mode`参数已完整记录。
- CLI 参考获取 webhook、审计、操作和记忆历史子命令的文档。
