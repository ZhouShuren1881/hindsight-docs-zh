## 多语言控制平面 {#multilingual-control-plane}

Hindsight Cloud UI 现已完全国际化。使用顶部导航栏中的 **语言选择器** 在 8 个支持的区域设置之间切换：**英语、西班牙语、法语、德语、葡萄牙语、日语、韩语和中文（简体）**。

- **每个页面和对话框** 已翻译 — 仪表板、计费、设置、团队、API 键、使用情况、支持聊天、管理和所有记忆库视图。
- **每个浏览器首选项** — 您选择的语言在会话中保持不变。
- **简体中文文档** — 文档网站的标题中还有一个语言选择器，用于切换到简体中文。

如果你发现翻译在上下文中读错了，请[打开一个问题](https://github.com/vectorize-io/hindsight/issues/new)——正确的*技术*语气（相对于直译但笨拙）是机器翻译经常失败的地方，我们宁愿听到它也不愿通过它。

## 支付宝结帐 {#alipay-at-checkout}

除了信用卡和借记卡之外，您现在还可以使用**支付宝**（支付宝）进行积分支付。 Stripe Checkout 向中国大陆的客户提供支付宝 — 显示的具体付款选项取决于您的区域设置和商户配置。

- **一次性使用授权** — 支付宝付款被授权一次收取一笔费用，因此不会保存到您的帐户中。
- **自动充值仅限卡** — 要启用自动充值，您仍然需要添加卡。您可以在支付宝购买后通过付款方式卡执行此操作。
- **现有卡流不变** — Visa、Mastercard、American Express 和其他主要网络继续像以前一样工作。

记忆数据视图有一个新的**星座**可视化，将记忆及其关系布置为交互式图表，实体视图获得一个新的**关系**选项卡，使用相同的引擎来探索实体到实体的连接。

![Constellation View — Hindsight 控制平面中的交互式记忆图](/img/blog/constellation-view.webp)

- **互动布局** — 缩放、平移并单击任何节点以检查底层记忆或实体。
- **颜色编码的事实类型**，所以世界事实、经验和观察很容易一眼就能区分出来。
- **图例叠加** 解释每个节点和边类型。

![实体共现图 - 同一引擎现在为“实体关系”选项卡提供支持](/img/blog/hindsight-0-5-2-entity-graph.webp)

## 更丰富的回忆视图 {#a-richer-memories-view}

“记忆数据”视图带来了一些生活质量的改进：

- **标签过滤** — 直接从视图中按一个或多个标签过滤记忆。
- **服务器端文本搜索** — 搜索记忆库中的所有记忆，而不仅仅是当前页面。
- **记忆摄取图表** 在记忆库统计页面上有 24 小时/7 天/30 天周期切换器，这样您就可以看到一段时间内的摄取趋势。
- **失败-整合深入分析** — 单击整合卡上的故障可准确查看哪些输入失败以及原因。
- **空状态 CTA** — 没有记忆的记忆库现在在数据视图中显示“添加文档”按钮。

## 心智模型，焕然一新 {#mental-models-refreshed}

心智模型视图已重建，以显示陈旧的表面和观察历史。

- **陈旧指标** 通过一键刷新显示模型何时比通知它的最新记忆更旧。
- **记忆召回控制** 让您无需离开视图即可预览模型返回的内容并调整其源查询。
- **近全屏细节模式** 每张卡上都带有 CompactMarkdown 预览，记忆细节内有一个 **观察历史** 面板，用于跟踪模型的演变过程。
- **指令详细模态
Think 视图中的**，用于检查上下文中的各个指令。

## 操作对话框升级 {#operations-dialog-upgrades}

异步操作对话框获得一组长期请求的控件：

- **重试** 直接从行中提取文件操作失败，无需重新上传。
- **取消** 挂起的操作，来自各个行和新的对话框级取消操作。
- **任务型过滤器** 将列表缩小到单一操作类型（整合、文件提取、心智模型刷新等）。
- **取消**和**处理**状态药丸让状态一目了然。
- **加载原始数据和元数据JSON** 用于需要调试时的任何操作。

## 导出和导入记忆库模板 {#export-and-import-bank-templates}

记忆库操作菜单现在包括**导出模板**和**导入模板**，因此您可以将记忆库的任务、指令、特征和结构设置保存为便携式文件，并将其应用到新的记忆库。

- **一键导出** 生成一个 JSON 模板，您可以将其签入版本控制。
- **创作导入** 可让您启动一个预先配置的新记忆库以匹配现有记忆库。
- **恢复整合** 操作——也是“操作”菜单中的新功能——当观察与潜在事实不同步时，重新运行记忆库的整合。

一轮 UI 基元更新（卡片、表格、状态丸、对话框）为整个控制平面提供了更紧密、更一致的视觉风格 - 每个视图都会自动继承新的外观。
