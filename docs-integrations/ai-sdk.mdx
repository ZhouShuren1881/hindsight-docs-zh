# Vercel AI SDK {#vercel-ai-sdk}

`@vectorize-io/hindsight-ai-sdk` 将 [Hindsight](https://hindsight.vectorize.io) 记忆集成到 [Vercel AI SDK](https://ai-sdk.dev)，提供五个开箱即用的工具，用于存入、召回和反思长期记忆。

## 安装 {#installation}

```bash
npm install @vectorize-io/hindsight-ai-sdk @vectorize-io/hindsight-client ai
```

## 工具参考 {#tools-reference}

注册了五个工具。`bankId` 在创建时即已固定，智能体无法更改。

| 工具 | 智能体提供的参数 | 构造函数控制的参数 |
|------|------------------------|-------------------------------|
| `retain` | `content`, `documentId`, `timestamp`, `context` | `async`, `tags`, `metadata` |
| `recall` | `query`, `queryTimestamp` | `budget`, `types`, `maxTokens`, `includeEntities`, `includeChunks` |
| `reflect` | `query`, `context` | `budget` |
| `getMentalModel` | `mentalModelId` | — |
| `getDocument` | `documentId` | — |

**为何如此划分？** 要记住什么、搜索什么等语义输入由智能体决定；成本预算、标签策略和异步模式等基础设施配置由应用控制。

## 构造选项 {#constructor-options}

除 `client` 和 `bankId` 外，所有选项均为可选。每个工具的选项按工具名称分组。

<CodeSnippet code={aiSdkTs} section="constructor-options" language="typescript" />

### `retain`

| 选项 | 类型 | 默认值 | 说明 |
|--------|------|---------|-------------|
| `async` | `boolean` | `false` | 发出请求后立即返回，不等待摄取完成 |
| `tags` | `string[]` | — | 附加到每条存入记忆的标签 |
| `metadata` | `Record<string, string>` | — | 附加到每条存入记忆的元数据 |
| `description` | `string` | 内置 | 覆盖模型看到的工具说明 |

### `recall`

| 选项 | 类型 | 默认值 | 说明 |
|--------|------|---------|-------------|
| `budget` | `'low' \| 'mid' \| 'high'` | `'mid'` | 控制检索深度和延迟 |
| `types` | `('world' \| 'experience' \| 'observation')[]` | 全部 | 将结果限制为这些事实类型 |
| `maxTokens` | `number` | API 默认值 | 限制返回的总 token 数 |
| `includeEntities` | `boolean` | `false` | 在结果中包含实体观测 |
| `includeChunks` | `boolean` | `false` | 在结果中包含原始来源文本分块 |
| `description` | `string` | 内置 | 覆盖模型看到的工具说明 |

### `reflect`

| 选项 | 类型 | 默认值 | 说明 |
|--------|------|---------|-------------|
| `budget` | `'low' \| 'mid' \| 'high'` | `'mid'` | 控制综合生成的深度和延迟 |
| `maxTokens` | `number` | API 默认值 | 响应的最大 token 数 |
| `description` | `string` | 内置 | 覆盖模型看到的工具说明 |
