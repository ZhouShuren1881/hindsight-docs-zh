### 命名配置文件 {#named-profiles}

当您需要在多个Hindsight部署之间切换时（例如本地、
舞台、制作）无需不断重写`~/.hindsight/config`，使用
命名配置文件。每个配置文件都是一个 TOML 文件，位于
`~/.hindsight/cli-profiles/<name>.toml` 并在每次调用时选择
`-p/--profile`（或通过设置`$HINDSIGHT_PROFILE`）。

<CodeSnippet code={cliSh} section="cli-profiles" language="bash" />

配置文件用编写 Unix 上的 `0600` 权限，因此API 密钥是
只有所有者可读。

**配置优先级**（最高的在前）：

1. 环境变量（`HINDSIGHT_API_URL`, `HINDSIGHT_API_KEY`)
2. 命名配置文件 — 显式 `-p <name>`，否则`$HINDSIGHT_PROFILE`
3. 共享配置文件（`~/.hindsight/config`，作者`hindsight configure`)
4. 默认（`http://localhost:8888`)

`HINDSIGHT_API_URL` / `HINDSIGHT_API_KEY` 始终覆盖配置文件值，这
使用安全`-p` 在脚本中，同时让 CI 通过以下方式注入凭据
环境。

## 全局选项 {#global-options}

|旗帜|说明|
|------|-------------|
|`-v, --verbose`|显示详细输出，包括request/response|
|`-o, --output <format>`|输出格式：pretty、json、yaml|

|`--help`|显示帮助|
|`--version`|显示版本|

## 控制平面 UI {#control-plane-ui}

直接从CLI启动基于Web的控制平面UI：

```bash
hindsight ui
```

这将使用配置中的 API URL 在端口 9999 上本地运行控制平面。用户界面提供：

- **记忆库管理** — 浏览和管理您所有的记忆库
- **实体浏览器** — 知识图谱可视化
- **查询测试** — 交互式记忆召回和反思测试
- **操作历史** — 查看摄取和处理日志

:::tip UI命令需要Node.js待安装。它会自动下载并运行 `@vectorize-io/hindsight-control-plane` 通过 npx 封装。
:::

## 交互式浏览器 {#interactive-explorer}

启动 TUI 浏览器，对您的记忆库进行视觉导航：

```bash
hindsight explore
```

资源管理器提供了一个交互式终端界面：

- **浏览记忆库** — 查看所有记忆库及其统计数据
- **搜索记忆** — 运行具有实时结果的记忆召回查询
- **查看记忆详情** — 打开记忆以查看其文本、元数据、实体和完整内容JSON字段
- **查看实体** — 探索知识图谱和实体关系
- **查看事实** — 浏览世界事实、经验和观察
- **浏览文档** — 查看源文档及其提取的记忆
