# TypeScript / JavaScript 客户端 {#typescript--javascript-client}

Hindsight API 的官方 TypeScript / JavaScript 客户端。支持**Node.js** 和 **Deno**。

## 安装 {#installation}

### Node.js {#nodejs}

```bash
npm install @vectorize-io/hindsight-client
```

### Deno {#deno}

无需安装，直接通过 `npm:` 说明符导入：

```typescript
import { HindsightClient } from "npm:@vectorize-io/hindsight-client";
```
