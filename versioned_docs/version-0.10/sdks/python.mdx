# Python 客户端 {#python-client}

Hindsight API 的官方 HTTP 客户端。已有在本地、Docker 或托管服务中运行的 Hindsight 服务器时，可使用这个带类型支持的 Python 客户端与它通信。

如果你愿意**在 Python 进程中嵌入并运行 Hindsight 服务器**（无需外部服务器），请参阅 [嵌入式 Python（hindsight-all）](./hindsight-all.md)。

## 安装 {#installation}

```bash
pip install hindsight-client
```
