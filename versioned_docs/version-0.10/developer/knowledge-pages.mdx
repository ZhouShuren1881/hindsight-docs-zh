# 知识页面 {#knowledge-pages}

**知识页面**是记忆库根据自身知识编写、持续更新的文档。每个页面回答一个问题，例如「这里有哪些组件？」或「我们的错误处理约定是什么？」，并在记忆库学到更多知识时自行改写。页面以文件夹组织，可以浏览、搜索，也可以映射到磁盘上成为普通 Markdown 文件。

其组织形式是 wiki，底层驱动它的是记忆。

## 简化的心智模型 {#mental-models-simplified}

知识页面*就是*一个[心智模型](./mental-models)，使用相同的综合机制、后台刷新和溯源能力。

区别在于使用它需要了解多少细节。心智模型直接提供各项机制的配置，包括读取哪些内容、何时重建以及如何修改自身。维护 wiki 不应要求用户考虑综合范围和刷新触发器，因此知识页面已经预先做出了这些决定：

- 基于记忆库的[观察](./observations)构建，即整合、去重后的认知，而不是原始对话细节。
- 当整合过程在其范围内产生新知识时，执行增量刷新，通过编辑文档更新内容，而不是重新生成。
- 从不读取其他页面，因此不会因页面互相引用而形成反馈循环。
- 获得更大的内容预算，因为它是一份文档，而不是一段回答。

你只需提供名称和问题。其他设置都有默认值，必要时可覆盖，所有心智模型设置仍然适用。具体默认值及其修改方式请参阅[知识页面 API](./api/knowledge-pages)。

## 像 wiki 一样组织 {#organized-like-a-wiki}

页面存放在文件夹树中。可以任意嵌套，页面名称在所属文件夹内唯一，删除文件夹会删除其子树。这就是完整的结构模型：一种层次结构，与手动整理文档的方式相同。

文件夹树让知识库可以方便地浏览，而不只是一个平铺的综合内容列表：`Architecture/`、`Runbooks/`、`Decisions/`，每个文件夹都保存自行保持最新的页面。

## 映射为真实文件 {#projected-as-real-files}

智能体已经知道如何操作文件系统，因此 CLI 可以将记忆库的知识库镜像到磁盘：

```bash
hindsight fs mount --bank my-bank
```

文件夹树会成为真实目录，每个页面则成为带 YAML frontmatter 的真实 Markdown 文件，由后台刷新循环保持最新。接下来，常用工具都可以照常使用：`ls`、`cat`、`grep`、`rg`、`fzf`、编辑器以及智能体的文件工具。无需 SDK、API 客户端，也无需学习新的操作术语。

同样的内容也可以通过 API 作为可移植的 Markdown 文件包获取，用于导出或提交到其他位置。

## 可搜索 {#searchable}

页面可在**文档级别**搜索：查询会返回排序后的完整页面及其片段。搜索结合全文匹配和语义匹配，在服务器端融合结果，不执行重排序，速度足以成为智能体首先使用的工具。

最后这一点很重要。搜索是智能体*选择*调用、会出现在对话记录中的工具。智能体主动请求的检索会为当前任务提供信息；未经请求、每轮都被推入上下文的检索内容，往往会让任务偏离方向。

这条路径与搜索单条记忆的[记忆召回](./retrieval)不同。使用页面搜索选择文档，使用记忆召回查找具体事实。

## 为什么不直接使用原始文件？ {#why-not-just-raw-files}

如果最终得到的是一棵文档树，我们是否只是重新发明了文件，也就是记忆系统原本要替代的东西？

区别在于底层机制。文件是信息逐渐过时的地方，最后编辑者的说法占据主导，矛盾悄然积累，却无人调和。缺乏维护时，手动管理的 wiki 会变成格式精美却不准确的文档，并非有人故意说谎，而是维持准确性是一项繁琐工作，最终常被搁置。

知识页面是经过处理的记忆之上的**映射视图**，类似数据库视图与表的关系。编写页面前，Hindsight 已经完成文件无法自行完成的工作：从原始会话、提交和文档中提取事实，去重，再通过整合协调矛盾。因此，当团队先决定采用 X，后来改为 Y，页面会写明 Y，还可以解释原因，而不会把两个决定保留在相隔一段的文字中。

原始文档仍然是关于*说过什么*的事实依据。页面则呈现经过协调后、关于*什么仍然成立*的事实。

这也解释了为什么页面能够自行修复，而不会不断腐化：页面是呈现形式，并非底层存储。删除一个页面不会丢失底层知识，它可以从记忆重新映射出来。手动维护的 wiki 被删除后，却没有这样的恢复能力。

## 使用页面 {#working-with-pages}

- **控制台** — 知识库视图展示文件夹树、页面内容以及哪些页面已落后。
- **HTTP API** — 完整端点说明请参阅[知识页面 API](./api/knowledge-pages)。
- **CLI** — `hindsight fs` 将记忆库镜像为本地文件夹中的 Markdown 文件。
- **智能体工具** — 智能体 SDK 提供 `agent_knowledge_*` 工具，让智能体在会话中列出、读取、创建和更新自己的页面。
