## 对比 {#comparison}

| 特性 | Retain | Recall | Reflect |
|---------|--------|--------|---------|
| **目的** | 存储信息 | 查找信息 | 根据信息推理 |
| **输入** | 原始文本／文档 | 搜索查询 | 问题／提示词 |
| **输出** | 记忆 ID | 排序后的事实与观察 | 推理后的回答 |
| **使用 LLM** | 是（提取） | 否 | 是（生成） |
| **使用观察** | 否 | 是 | 是 |
| **性格倾向** | 否 | 否 | 是 |
