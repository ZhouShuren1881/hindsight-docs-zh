## 对比 {#comparison}

| 特性 | Retain | Recall | Reflect |
|---------|--------|--------|---------|
| **用途** | 存储信息 | 查找信息 | 对信息进行推理 |
| **输入** | 原始文本/文档 | 搜索查询 | 问题/提示 |
| **输出** | 记忆 ID | 排序后的事实和观测 | 推理生成的回答 |
| **使用 LLM** | 是（提取） | 否 | 是（生成） |
| **使用观测** | 否 | 是 | 是 |
| **性格倾向** | 否 | 否 | 是 |
